# План стабильного выпуска 1.0 (02.10.2026)

**Статус 02.10.2026: выполнен, v1.0.0 опубликована.** Не закрыто: вычитка узбекского носителем, скриншоты на сайт.

Цель: публичный релиз на GitHub для англо-, русско- и узбекоязычных пользователей.
Новых функций нет — только стабилизация, локализация, оформление.

## Что нашёл при ревизии (02.10)

Состояние репозитория:
- На GitHub лежит v0.2.0 (ветка `main`, релиз с APK от 30.09). Локально — ветка `master`, 9 коммитов
  впереди (v0.2.1 … v0.4.6), не запушены. Релиз на GitHub один — v0.2.0. GitHub Pages выключены.
- Описание и topics репозитория уже на английском, README — русский с английским абзацем в конце.

Код — что «недожато»:
1. **Интерфейс только русский.** В `strings.xml` 2 строки; ~195 русских литералов лежат прямо в Kotlin
   (MainActivity 114, Models 19, TranscriptionService 18, Pipeline 15, Background 13, Formatter 7,
   RecorderService 5, App 3, AudioDecoder 1). Названия каналов уведомлений, стадии прогресса
   («поиск говорящих»), тексты ошибок, подписи моделей, инструкции производителей — всё в коде.
2. **Текст результата русский независимо от языка:** «Транскрипция: …», «длительность», «говорящих»,
   «Спикер N», «(речь не обнаружена)», дата в формате `dd.MM.yyyy` с `Locale("ru")` (Formatter.kt).
   Для английского пользователя файл .txt выйдет с русскими заголовками.
3. **Умолчания — для русского:** модель по умолчанию GigaAM ru, язык Whisper «ru». Англоязычный пользователь
   при первом запуске получит русскую модель. Нужно выбирать по языку системы: en → Whisper + "en",
   uz → GigaAM Multilingual, ru → GigaAM v3.
4. **Выбор языка Whisper — только ru/en/авто** (MainActivity:700); «uz» в списке нет, хотя Settings его
   подразумевает.
5. **Продолжение после убийства процесса есть только с разделением говорящих.** Без диаризации
   (`Pipeline.plain`) точек нет — после перезапуска распознавание начинается с нуля. На длинных файлах
   без спикеров это та же проблема, что мы чинили неделю.
6. **Нет защиты от бесконечного круга.** Если часть N падает нативно, система перезапускает сервис,
   и он снова идёт в ту же часть — так было 32 раза подряд на Huawei. Нужен счётчик: третье падение
   на одной точке → для этой части пропустить отпечаток говорящих / отметить задачу ошибкой с текстом
   «часть N не удалось обработать», а не крутить вечно.
7. **Android 15 (targetSdk 35): foreground-сервис типа `dataSync` ограничен 6 часами в сутки.**
   После лимита система вызывает `onTimeout()` и останавливает сервис. Для телефонов на Android 15
   (Pixel, Samsung 2025) расшифровка долгих записей упрётся в это. У нас `onTimeout` не реализован.
   Варианты: тип `specialUse` (без лимита, для установки вне Play допустим) или `onTimeout` →
   сохранить точку и показать «продолжить» при открытии приложения. Рекомендую `specialUse`.
8. **Иконка — одиночный vector drawable**, не adaptive icon: на современных лаунчерах будет в
   белом/сером кружке или обрезана. Нужен `mipmap-anydpi-v26/ic_launcher.xml` (foreground+background)
   плюс monochrome для Android 13 тем.
9. Журнал `bg.log` и строки диагностики («отпечаток: …», «трассировка: …») остаются — это нормально,
   но кнопку «Отправить журнал» надо подписать по-английски и объяснить, что в нём нет содержимого записей.
10. Название. В EN «Transcriber» — слишком общее для поиска на GitHub/в Obtainium; applicationId менять
    нельзя (сломает обновление поверх). **Решение владельца (02.10): имя — Scribbit**, одно для всех
    локалей (латиницей, без транслитерации). Меняем только `android:label`, README, Pages и заголовок
    релиза; applicationId остаётся com.egorchenkov.transcriber. Переименование репозитория на GitHub
    (android-transcriber → scribbit) — отдельное решение: старые ссылки GitHub редиректит, но ссылка
    в Obtainium/закладках у пользователей v0.2.0 сменится.

Что в порядке и трогать не надо: приватность (хуки, denylist, .gitignore), подпись одним ключом,
размер APK под лимит Telegram, sherpa-onnx 1.13.8, диаризация и продолжение с точки (с 0.4.6 проверено
на одном прогоне на Huawei).

## План работ

Порядок — по важности; каждый шаг = отдельный коммит, APK в тему после шагов 2, 4, 6.

**Шаг 1. Выровнять git.** Локальную `master` переименовать в `main`, запушить 9 коммитов. Релизы
0.2.1–0.4.6 на GitHub не публиковать — только итоговый 1.0.0.

**Шаг 2. Надёжность (пункты 5–7).** Точки продолжения без диаризации (по 5 мин, как со спикерами);
счётчик падений на одной точке с выходом в ошибку; тип сервиса `specialUse` + `onTimeout` на всякий случай.
Проверка: jvm-check с `KILL_AFTER`, прогон на телефоне.

**Шаг 3. Локализация (пункты 1–4).** Все строки → `res/values/strings.xml` (EN — база),
`values-ru`, `values-uz` (узбекский на латинице, как в системе Android). Формат результата —
по локали приложения (заголовки, «Speaker N», дата). Умолчания модели/языка по языку системы.
Переключатель языка интерфейса в настройках (на случай, если система не на одном из трёх) —
через `AppCompatDelegate.setApplicationLocales`, без перезапуска. Узбекский перевод делаю сам,
но нужна вычитка носителем: отдам таблицу строк файлом на проверку.

**Шаг 4. Внешний вид.** Adaptive icon (пункт 8); проход по экранам на предмет лишнего текста
(карточка фона — только когда она нужна; счётчики заморозок — в настройки); версия в настройках.

**Шаг 5. README и страница.** README полностью на английском (установка, модели, приватность, сборка),
русская и узбекская версии — `README.ru.md`, `README.uz.md`, ссылки сверху. GitHub Pages из папки
`docs/` — одна страница `index.html` (EN, переключатель RU/UZ): что делает, скриншоты, кнопка
«Download APK» на последний релиз, Obtainium, приватность, список моделей и лицензий. Для скриншотов
нужны 3–4 снимка с телефона (главный экран, результат, настройки) — на сервере эмулятора нет.
Привязать домен не нужно: `egorchenkov.github.io/android-transcriber`.

**Шаг 6. Выпуск 1.0.0.** Тег, релиз на GitHub с APK и заметкой на английском, проверка Obtainium.
В CLAUDE.md — снять «не проверено на телефоне», отметить состояние 1.0. Дальше — только багфиксы 1.0.x.

Оценка: шаги 1–2 — один заход; шаг 3 — самый объёмный (≈200 строк × 3 языка, правка всех экранов);
4–6 — короткие, но ждут скриншотов и вычитки узбекского.
