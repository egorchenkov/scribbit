Three languages, best model for each

Russian — GigaAM v3 with punctuation. Uzbek and Kazakh — GigaAM Multilingual. English and ~100 others — Whisper Small.

Who said what

Speaker separation for meetings and calls: “Speaker 1: …”. Set the number of participants or leave it on auto.

Hours-long recordings

Processed in 5-minute parts; memory does not grow with length. If the system kills the app, it resumes from the last finished part.

Private by design

Models are downloaded once. After that the app never touches the network — no cloud, no analytics.

Fits your workflow

“Share” a voice message from Telegram or any file; record in the background; pick several files at once.

Text the way you need it

Copy, share to a messenger or an LLM, save as .txt. Timestamps optional.

Getting started

  1. Download the APK from Releases and open it on the phone; allow installation from this source.
  2. Tap the gear, download a speech model (≈215–360 MB) and, for meetings, “Speaker separation” (40 MB).
  3. Record, choose files, or share audio into Scribbit — then “Transcribe”.

Updates: add the repository to Obtainium. Phones with aggressive battery managers (Huawei, Xiaomi, …) need a one-time setting — the app shows a checklist.

Три языка, лучшая модель для каждого

Русский — GigaAM v3 с пунктуацией. Узбекский и казахский — GigaAM Multilingual. Английский и ~100 других — Whisper Small.

Кто что сказал

Разделение говорящих для совещаний и созвонов: «Спикер 1: …». Укажите число участников или оставьте «авто».

Многочасовые записи

Обрабатываются частями по 5 минут; память не растёт с длиной. Если система убьёт приложение, работа продолжится с последней готовой части.

Приватность по умолчанию

Модели скачиваются один раз. Дальше приложение не выходит в сеть — ни облака, ни аналитики.

Встраивается в привычки

«Поделиться» голосовым из Telegram или любым файлом; запись в фоне; несколько файлов разом.

Текст — как удобно

Скопировать, отправить в мессенджер или LLM, сохранить .txt. Таймкоды по желанию.

Как начать

  1. Скачайте APK со страницы Releases и откройте на телефоне; разрешите установку из этого источника.
  2. Шестерёнка → скачайте модель распознавания (≈215–360 МБ) и, для совещаний, «Разделение говорящих» (40 МБ).
  3. Запишите, выберите файлы или поделитесь аудио в Scribbit — затем «Транскрибировать».

Обновления: добавьте репозиторий в Obtainium. Телефонам с жёстким менеджером батареи (Huawei, Xiaomi, …) нужна разовая настройка — приложение показывает список шагов.
