# Кросс-платформа: iPhone, Mac, Windows

Состояние на конец сентября 2026 г. Контекст: личное офлайн-приложение для транскрибации (сначала русский, затем английский и узбекский), нужна диаризация (разделение говорящих). Android — Kotlin + sherpa-onnx.

## 1. Как поставить своё приложение на iPhone без App Store

Для сборки под iOS в любом случае нужен Mac с Xcode: собрать и подписать IPA на Linux или Windows нормальным способом нельзя.

- **Платный Apple Developer Program ($99 в год, аккаунт физлица).**
  - Ad hoc: до 100 зарегистрированных устройств каждого типа в год. Ревью нет, сборка живёт до конца срока профиля, то есть около года. Для одного-двух своих телефонов этого достаточно.
  - TestFlight: у внутренних тестировщиков (до 100 человек) ревью нет. Каждая сборка живёт 90 дней, потом нужно загрузить новую.
  - Оплата из Узбекистана: регистрация физлица возможна, но нужна международная карта (Visa или Mastercard) и Apple ID с подтверждённой личностью. Это стоит проверить при регистрации: список стран Apple иногда меняется.
- **Бесплатный Apple ID.** Установка из Xcode, AltStore, SideStore или Sideloadly.
  - Подпись действует 7 дней, потом приложение перестаёт запускаться до повторной подписи. SideStore продлевает подпись сам, прямо на телефоне, остальным инструментам нужен компьютер.
  - Одновременно можно держать не больше 3 приложений (включая сам SideStore) и не больше 10 новых в неделю. Обходной путь — LiveContainer.
  - Для личного использования работает, но ломается в самый неподходящий момент. Для рабочих переговоров это ненадёжно.
- **Альтернативные маркетплейсы (AltStore PAL, Epic и др.).** Доступны только в ЕС, Японии (с 2026 г.) и Бразилии (с iOS 26.5). Регион определяется по Apple ID и фактическому местоположению. **К Узбекистану не применимо.** Кроме того, даже там нужен платный аккаунт разработчика и нотаризация у Apple.
- **Веб-приложение или PWA.**
  - Технически это возможно: в iOS 26 Safari включил WebGPU. Whisper запускается через transformers.js (ONNX Runtime Web) или whisper.cpp в WASM. У sherpa-onnx тоже есть WASM-сборка, в том числе с диаризацией.
  - Ограничения iOS такие:
    - вкладке доступно примерно 1,5–3 ГБ памяти, при превышении Safari её перезагружает;
    - буфер WebGPU — до 256 МБ;
    - кеш моделей iOS может удалить, если PWA долго не открывали;
    - при блокировке экрана или сворачивании обработка останавливается, фоновой работы нет;
    - «Поделиться → в PWA» из Telegram работает плохо.
  - Реально: небольшие модели (Whisper tiny, base, small) на коротких файлах. Часовая встреча с диаризацией на iPhone в браузере — ненадёжно.
- **Стоит ли городить огород?** Только ради iPhone — нет. Готовые iOS-приложения (раздел 2) дешевле $99 в год и уже умеют диаризацию. Своё iOS-приложение имеет смысл, если нужна именно GigaAM (лучшее качество на русском) или узбекская модель, которых в готовых приложениях нет.

## 2. Готовые аналоги (офлайн, акцент на диаризацию)

Общая оговорка по языкам. Почти все эти приложения используют Whisper. Русский Whisper распознаёт хорошо (large-v3 и turbo). Узбекский формально поддерживается, но качество слабое. Нормального офлайн-узбекского в готовых приложениях по сути нет: это аргумент в пользу своего приложения (Omnilingual или дообученные модели через sherpa-onnx).

### iOS (iPhone, iPad)
- **Whisper Notes** — около $7.99 разово, аккаунта нет. Есть iPhone и Mac.
  - Диаризация полностью на устройстве, начиная с версии 1.8.5 для iPhone: pyannote community-1 в Core ML. Разметка появляется после записи.
  - Поддерживает 100+ языков Whisper, включая русский.
  - Для переговоров это самый прямой готовый вариант.
- **TranscriAI, Audiscript, ScribeAI** — Whisper на устройстве с диаризацией. Модели цен разные, часто подписка. Перед покупкой стоит проверить на своём файле.
- **Aiko** (Sindre Sorhus) — бесплатный, хорошее качество Whisper, iPhone и Mac. **Диаризации нет.**
- **Whisper Transcription** (Good Snooze, от автора MacWhisper) — iOS-версия MacWhisper. Есть ли диаризация на iOS, я не подтвердил, надо проверить в описании App Store.

### macOS
- **MacWhisper** (Jordi Bruin) — лучший выбор на Mac.
  - Pro через Gumroad стоит €59 разово. В Mac App Store: $6.99 в месяц, $29.99 в год или $99.99 навсегда.
  - Диаризация входит в Pro и помечена как бета. В тестах: около 91% верной атрибуции при 2 говорящих, около 80% при 3.
  - Русский поддерживается, модели от tiny до large-v3-turbo.
- **Whisper Notes для Mac** — та же диаризация, что и на iPhone.
- **noScribe** — бесплатный, GPL. Whisper + pyannote, диаризация полноценная. Есть сборки для Windows, macOS и Linux, интерфейс в том числе на русском. Медленнее, зато заточен под интервью.
- **Vibe** — бесплатный, open source, работает офлайн. Есть диаризация и редактирование спикеров. macOS, Windows, Linux.
- **Buzz** — бесплатный, open source. Есть «Speaker identification» (запускается после транскрибации), но на длинных файлах бывают ошибки.
- **SuperWhisper** — в первую очередь диктовка, подписка. Файлы и «Speaker-separated meetings» поддерживает, но лучше всего это работает на облачных моделях (Nova). Для офлайн-переговоров это не лучший выбор.
- **VoiceInk** — только диктовка, файлы не транскрибирует и диаризации нет. Не подходит.

### Windows
- **noScribe** — главный бесплатный вариант с диаризацией (pyannote).
- **Vibe** — бесплатный, с диаризацией, установка проще, чем у noScribe.
- **Buzz** — бесплатный, диаризация есть, на Windows встречаются баги.
- **Whisper-WebUI** (jhj0517) — веб-интерфейс, диаризация через pyannote. Нужен токен Hugging Face и согласие с лицензией модели, плюс Python и желательно GPU. Слишком «гиковский» вариант.
- **Subtitle Edit** — редактор субтитров со встроенным Whisper. Диаризация только через внешний WhisperX, отдельная настройка. Не основной инструмент.
- **SuperWhisper** — есть версия для Windows, но оговорки те же, что для macOS.

## 3. Один стек на Android, iOS, macOS и Windows

- **Flutter + пакет `sherpa_onnx`.** Версия 1.13.8 вышла в сентябре 2026 г.
  - Официальные платформы: Android, iOS, macOS, Windows, Linux, Web.
  - В Dart API есть офлайн-распознавание (Whisper, NeMo/GigaAM и др.) и **диаризация**: в `dart-api-examples/speaker-diarization` есть готовый пример.
  - Это единственный вариант, где один и тот же движок, модели и интерфейс работают на всех четырёх платформах из коробки.
  - Минусы: нужно переписать уже сделанный Kotlin-интерфейс на Dart. Для iOS и macOS всё равно нужны Mac и подпись.
  - Оценка: портирование готовой Android-логики занимает 2–4 недели работы с ИИ-агентом, плюс настройка сборок под каждую ОС.
- **Kotlin Multiplatform / Compose Multiplatform.** Бизнес-логика и интерфейс на Kotlin переиспользуются, поэтому нынешний код не выбрасывается. Такие приложения уже есть (Notely Voice — CMP, Android + iOS, Whisper).
  - Минус: готового KMP-модуля для sherpa-onnx нет. Нужно писать обёртки самому: для iOS через C API/cinterop или Swift-обёртку, для десктопа через JVM/JNI.
  - Windows и macOS в CMP запускаются как JVM-приложение, установщики получаются тяжелее.
  - Это самый естественный путь из текущего кода, но на старте прослойки дают больше возни, чем Flutter.
- **React Native + `react-native-sherpa-onnx`** (сторонний TurboModule). Поддерживает Android и iOS, есть распознавание, диаризация, VAD, потоковая диаризация.
  - Десктоп нормально не поддерживается: Windows и macOS в React Native — отдельная история.
  - Имеет смысл только для «телефонной» пары.
- **Tauri или Electron — только десктоп.** sherpa-onnx можно подключить через Node API (Electron) или Rust/C API (Tauri). Именно так устроен Vibe.
  - Для Mac и Windows это разумно, но с мобильными платформами код не делится, получается отдельный проект.

Итог по трудоёмкости, от меньшей к большей:
- готовые приложения — ноль разработки;
- Flutter — один проект на всё, но переписать интерфейс;
- KMP — сохраняем Kotlin, но сами пишем мосты к sherpa-onnx;
- отдельное приложение под каждую ОС — дороже всего.

## Итоговая рекомендация

Сейчас доводить Android-версию на Kotlin + sherpa-onnx: код уже есть, и только она даёт GigaAM для русского, узбекский и диаризацию на телефоне. Логику (конвейер модели → VAD → распознавание → диаризация → склейка текста) держать отдельно от интерфейса, а модели и настройки описывать в конфиге, чтобы потом их можно было перенести. На iPhone и Mac пока не писать своё, а поставить **Whisper Notes** (около $8, диаризация на устройстве) или **MacWhisper Pro** (€59). На Windows взять **noScribe** или **Vibe** (бесплатно, с диаризацией). Все они работают на русском. К собственной кросс-платформе возвращаться, только если готовые приложения не устроят качеством на русском или узбекском. Тогда выбрать **Flutter + sherpa_onnx** (одно приложение на все ОС, диаризация есть в Dart API) и заложить $99 в год на Apple Developer плюс доступ к Mac. Бесплатный sideload на 7 дней и PWA для рабочих переговоров ненадёжны, альтернативные маркетплейсы в Узбекистане недоступны.
