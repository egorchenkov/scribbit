# android-transcriber — Android-приложение для офлайн-транскрибации аудио

Цель: простое Android-приложение (APK для личной установки, без Play Store), которое
транскрибирует аудио прямо на телефоне.

Сценарии:
- «Поделиться» аудиофайлом из любого приложения (Telegram и др.) → транскрибация;
- выбор одного или нескольких файлов внутри приложения → транскрибация пакетом;
- результат — текст: скопировать, поделиться, сохранить.

Ориентиры по моделям (исследовать и выбрать в работе):
- Whisper на устройстве: whisper.cpp (ggml-модели, как у MacWhisper), варианты tiny/base/small/turbo, квантизации;
- альтернативы: faster/distil-whisper, Vosk, sherpa-onnx;
- на сервере платформа уже распознаёт речь: /srv/platform/tgbot-runtime/runtime/{asr,local_asr,local_whisper_worker}.py — только как справка, код не править.

Принципы: простота, офлайн-работа, русский язык в приоритете. Сборка APK — здесь, в репозитории.
Тема в группе: «Транскрибатор Android».
