# android-transcriber — Android-приложение для офлайн-транскрибации аудио

Цель: простое Android-приложение (APK для личной установки, без Play Store), которое
транскрибирует аудио прямо на телефоне.

Сценарии:
- «Поделиться» аудиофайлом из любого приложения (Telegram и др.) → транскрибация;
- выбор одного или нескольких файлов внутри приложения → транскрибация пакетом;
- результат — текст: скопировать, поделиться, сохранить.

Ориентиры по моделям (исследовать и выбрать в работе):
- Whisper на устройстве: whisper.cpp (ggml-модели, как у MacWhisper), варианты tiny/base/small/turbo, квантизации;
- альтернативы: faster/distil-whisper, Vosk, sherpa-onnx;
- у владельца на сервере есть свой ASR-сервис (путь — в системном промпте темы) — только как справка, код не править.

Принципы: простота, офлайн-работа, русский язык в приоритете. Сборка APK — здесь, в репозитории.

## Приватность — жёсткое правило (решение владельца, 30.09.2026)
Репозиторий публичный. Записи, расшифровки и любые фрагменты реальных встреч, присланные в тему
для проверки, в git не попадают НИ ПРИ КАКИХ обстоятельствах: ни файлом, ни цитатой в docs,
тестах, комментариях или сообщениях коммитов. Работать с ними — только вне репозитория
(`~/.local/state/…`, `/tmp`, `~/dev/.cache/`); в документах — лишь обезличенные метрики.
Для тестов качества — открытые корпуса (AMI и т.п., тоже вне git) или синтетика.
Предохранители: `.gitignore` (аудио/видео/srt/vtt/rttm), хуки `.githooks/` (включаются
`git config core.hooksPath .githooks`) — блокируют медиа, файлы >300 КБ и слова из приватного
стоп-списка `~/.config/android-transcriber/private-denylist.txt` (вне репо; пополнять именами/терминами
из каждой новой присланной записи). Перед каждым push — проверить `git status` и diff глазами. Хук не обходить.
